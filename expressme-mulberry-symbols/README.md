# ExpressMe Mulberry symbols

The 23 [Mulberry Symbols](https://mulberrysymbols.org) used for core vocabulary in the
ExpressMe Communicator AAC app for iPad, published here as the Creative Commons
Attribution-ShareAlike 4.0 licence requires.

- `original/` holds the upstream SVGs, unmodified and renamed to the word they show.
- `adapted/` holds the versions bundled in the app. CSS classes are folded into attributes and
  coordinates are rounded to one decimal place. The pictures are unchanged.
